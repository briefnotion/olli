# Working on olli

## Scope discipline

When a change is scoped to a named function (or a small, explicitly named set
of functions), restrict edits to exactly those functions. If accomplishing
the goal seems to require touching other functions too, stop and flag it as
a question before editing them - list which functions and why - rather than
deciding on your own to expand scope. Wait for explicit go-ahead before
touching anything beyond what was named.

This applies even when the extra change looks like an obvious improvement or
a related bug fix - flag it instead of folding it in, unless separately
asked.
